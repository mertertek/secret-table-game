### Realtime (gerçek kanal)
- **Üye olmayan** anon kullanıcı `room:<id>` özel kanalına abone → `CHANNEL_ERROR:
  "Unauthorized: You do not have permissions to read from this Channel topic"` (doğru ret).
- **Üye** kullanıcı → `SUBSCRIBED` / kanal `state: joined`, `isConnected: true`,
  soket JWT'si set (691 karakter, `authenticated`).
- **Sinyal teslimi**: bot oy verdi (rev 8) → tarayıcı `room_revision_changed {roomId,
  revision:8}` broadcast'ini aldı (payload yalnız `id`+`roomId`+`revision`; gizli yok) →
  yetkili görünümü HTTP'den yeniden aldı → UI ~saniyeler içinde güncellendi. Oyun rev
  8→12 boyunca tarayıcı senkron kaldı.
- **İki sinyal/rev** (`commit_move` explicit + `game_states` trigger) `roomChannel`'de
  1 sn'lik aynı-sürüm bastırması + `useRoomState` `queueMicrotask`/`revision>lastRevision`
  ile tek refetch'e iniyor.

### Bağlantı durumu + toparlanma (tarayıcıda)
- `offline` olayı → "Bağlantı kesildi" şeridi + kırmızı nokta + `ActionPanel` düğmeleri kapalı.
- `online` olayı → şerit temizlendi, yeşil nokta, `resync` tetiklendi (`needResync=true` →
  sonraki görünüm tam, eski cue kuyruğu boş). 4 sn sonra da `connected` kaldı.
- **Token yenileme**: `auth.refreshSession()` → token değişti; `realtime` yeni token'ı aldı
  (`_handleTokenChanged` → `setAuth`), kanal `joined` kaldı; sonraki API çağrısı başarılı.
- Sayfa yenileme → aynı oturum, aynı koltuk/rol/aşama, `submittedVote` korundu, çift oy yok.
