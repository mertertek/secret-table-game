# QA kayıtları

Bu klasördeki Markdown raporları ekran görüntülerine göreli yolla (`d12/…jpg`,
`e2e/…png`) bakar. **Görseller depoya dahil değildir** (`.gitignore`: ~260 MB, public
depo boyutu). Raporlardaki ölçüm tabloları ve sonuçlar metin olarak tamdır; kareler
geliştirme makinesinde durur ve istenirse ayrı bir yayın (Release ek dosyası) olarak
paylaşılır.

Screenshots referenced by the reports in this folder are intentionally not tracked
in git (see `.gitignore`); the reports' tables and conclusions are self-contained.
