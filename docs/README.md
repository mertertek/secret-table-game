# Documentation index

Secret Table was developed in Turkish and its working logs were kept in Turkish;
everything user-facing — the game itself, the README and the documents below — is
bilingual or English.

## English

| Document | What it is |
| --- | --- |
| [`../README.md`](../README.md) | Project overview, features, screenshots and how to run it locally. |
| [`SETUP.md`](SETUP.md) | Step-by-step guide to deploying your own copy on your own Supabase and Vercel projects. |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | How the pieces fit: package map, the path of a move, determinism, privacy, the scene pipeline and the live look channel. |
| [`ASSETS.md`](ASSETS.md) | Inventory of every 3D and media asset, with dimensions, measurements and the font licences. |
| [`../CONTRIBUTING.md`](../CONTRIBUTING.md) | How to build and test, package boundaries, and what a pull request should contain. |
| [`../NOTICE.md`](../NOTICE.md) | Attribution for the *Secret Hitler* ruleset and third-party material. |
